## نص إنجليزي مبسط
Hello everyone. We are Team ORBITA.
Long space missions create many challenges for human health.
ORBITA is a software-only platform. It does not need any hardware.
It combines three machine-learning models.
Isolation Forest screens for unusual patterns.
Random Forest creates an illustrative next-step forecast.
K-Means groups similar simulated profiles.
Our dashboard explains the outputs and stores simulation records locally.
Our current data is synthetic. ORBITA is not a medical device and does not diagnose.
ORBITA: From separate signals to a clearer picture. Thank you.

## أسئلة متوقعة
**Why did you use three models?**
Each model has a different role: anomaly screening, illustrative forecasting, and pattern grouping.

**Is the forecast medically reliable?**
No. It is trained on synthetic sequences and is only a software demonstration.

**What is the innovation?**
The integrated workflow: a digital profile, multiple ML perspectives, a simple explanation panel, and a local simulation history.

**Why no hardware?**
The challenge is addressed through software simulation and AI analysis. This makes the prototype easier to test, reproduce, and demonstrate.

**What does a radiation index mean?**
It is an abstract synthetic input only, not a physical dose or real sensor reading.
